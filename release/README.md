# Empire release

**[Empire.html](Empire.html)** is the whole game in one file. Download it and open it in any modern browser
(Chrome, Edge, Firefox, Safari), on a computer or phone. Nothing to install, and no server needed.

- **On this device**: play alone against the computer, or hot seat with friends on one screen. Games are saved
  in the browser.
- **Online (async)**: create a game, share the six-letter code, and take turns whenever you like. Friends
  need the same file. Online play goes through the Empire relay (`docs/RELAY.md`), which is built into the file.

Rebuilt with `npm run release` whenever the game changes.
