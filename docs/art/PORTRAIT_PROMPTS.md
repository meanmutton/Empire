# Leader portrait prompts

Each code block below is a complete prompt: copy one, paste it into your image tool, and you're done.
Save each result under the file name shown above its prompt. Any size or format is fine; a script crops,
resizes and compresses them for the game.

Suggested order: generate one portrait per great power first (for example Halvorsen-Okafor, Ryn'sora,
Thaurrun, Draskin and ARBITER). Once the style is settled, do the rest.

The minor factions' envoys follow the leaders, in the same batches as their lore.
