# Icon artwork

Drop replacement artwork for any icon here, named after its key with the colon as a dash, e.g.
`imp-mine.png`, `res-energy.webp`, `queue-ship.svg`. The game uses the file instead of the built-in look
(an emoji for resources and kinds of build, an SVG drawing for improvements) everywhere that icon appears.
Square images, 64–128 px, on a transparent background work best. Keys are listed in `ICONS` in
`src/ui/icons.ts`.
